## Important source-language note

This is a **source-faithful catalogue**, not a newly translated religious text.

Madhwa Festivals itself says that most Dasara Padagalu lyrics are published in **Kannada and English**, while the site also contains Sanskrit stotras and transliterations. Therefore a Sanskrit version is **not invented** for Kannada Dasara Padagalu where the source does not provide one.

For each record:

- **Kannada** = Kannada title/text where the source provides it.
- **Sanskrit** = Sanskrit title/text where the source provides it.
- **English** = English title/transliteration or English version where the source provides it.
- `SOURCE` means the complete item should be opened from its original Madhwa Festivals page before importing its full lyrics into the app.

# 10. SOURCE-FIDELITY RULE FOR THE APP

Do **not** automatically generate Sanskrit from a Kannada Dasara Pada.

Do **not** automatically translate a Sanskrit Stotra into English and present it as the original source.

Instead store the three fields independently:

```text
Kannada
↓
Source-provided Kannada text

Sanskrit
↓
Source-provided Sanskrit text

English
↓
Source-provided English text / transliteration
```

If a source page only contains Kannada + Roman transliteration:

```yaml
sanskrit: null
kannada: <source Kannada>
english: <source transliteration / translation if present>
```

This preserves the actual Madhwa Festivals source instead of creating artificial versions.
