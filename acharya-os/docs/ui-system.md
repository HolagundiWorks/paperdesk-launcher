# AcharyaOS priest-facing UI system

## Display contract

- Landscape only.
- True black canvas (`#000000`) with white primary text.
- Orange (`#FF6A00`) is reserved for the primary action, current ritual state, selected calendar dates and important observances.
- No decorative gradients, shadows or rounded cards. Structure comes from spacing, typography and subtle grey dividers.

## Accessibility

- Primary reading text: 18–20sp with increased line spacing.
- Page titles: 24sp; major values: 30–32sp.
- Supporting text never falls below 14sp.
- Interactive targets are at least 44–48dp high.
- Populated measurement fields keep visible unit labels.
- Compact button captions retain full spoken descriptions for accessibility services.
- Long ritual instructions scroll vertically instead of shrinking.

## Navigation

- A persistent bottom bar shows the current page name.
- Previous and next controls remain in fixed positions with 48dp targets.
- The Hari Sarvottama / Vayu Jeevottama motto is supporting context rather than the strongest visual element.
